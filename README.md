# cv2-mss-zone-creator
Script that can generate the capture zone used by libraries such as mss for screenshots

## Dependencies

1. Everything in the [requirements.txt](requirements.txt)

## Usage
```python cv2-mss-zone-creator.py```

1. A screenshot of your monitor will be presented to you
2. Drag a box of the region you want to isolate
3. Press ENTER
4. Check terminal where this script was ran for an output of your zone
